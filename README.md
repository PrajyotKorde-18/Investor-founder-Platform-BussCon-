# 🚀 BussCon: Founder-Investor & Operations Analytics Platform

Welcome to **BussCon**, a full-stack web platform designed to seamlessly connect ambitious founders with strategic investors while also providing powerful operations analytics. 

## 📖 Overview
BussCon acts as a bridge and a dashboard. For founders, it's a place to submit innovative ideas, receive uniqueness checks, and find the right investors. For investors, it offers a streamlined pipeline to discover, evaluate, and connect with promising startups. It also includes comprehensive analytics and reporting tools to support operational excellence.

## ✨ Key Features
* **Idea Submission & Uniqueness Checks:** Founders can securely submit their project ideas and get insights on market uniqueness.
* **Investor Matching (The Pipeline):** Smart matching connects founders with investors whose interests align with the startup's domain and stage.
* **Analytics Dashboards:** Real-time operational analytics for tracking project metrics, user engagement, and platform performance.
* **Automated Reporting:** Generate comprehensive reports to keep stakeholders informed.
* **Legal Support:** Integrated resources and workflows to assist with the legal aspects of founding and funding.

## 🛠️ Technology Stack
* **Frontend:** React (Vite)
* **Styling:** CSS
* **Build Tool:** Vite

## 🚀 Getting Started locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PrajyotKorde-18/Investor-founder-Platform-BussCon-.git
   ```
2. **Navigate to the app directory:**
   ```bash
   cd Investor-founder-Platform-BussCon-/busscon-app
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Run the development server:**
   ```bash
   npm run dev
   ```
